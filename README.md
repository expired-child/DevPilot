# DevPilot

DevPilot 是一个可扩展的 Chrome 开发者效率插件。当前版本提供独立的 **Form Clipboard / 表单剪贴板** 模块和 **书签搜索** 模块。

## 开发

```bash
npm install
npx playwright install chromium
npm run lint
npm run typecheck
npm test
npm run build
```

构建产物位于 `dist/`。在 Chrome 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”并选择 `dist`。
点击工具栏中的 DevPilot 图标会打开常驻侧栏，复制、编辑和预览填充都在这里完成。

测试使用真实 Chromium DOM，覆盖弹窗与多表单选择、隐藏页签、重复字段、复制粘贴往返和联动重渲染。

## 快捷键

- `Alt + Shift + C`：复制当前表单。页面有多个表单且焦点或弹窗无法确定目标时，会提示先聚焦目标输入框，或到侧栏选择。
- `Alt + Shift + V`：直接把最近复制的表单填充到当前页，跳过预览（页内 toast 汇总结果；唯一字段自动追加 `-2`/`-3` 后缀避免重复）。目标不明确或模板变量未填写时不会修改页面，并会提示原因。侧栏中的填充入口会先打开预览，唯一字段可在预览中手动调整。
- `Alt + Shift + F`：打开书签搜索——侧栏自动打开（或聚焦）并跳转到书签搜索页，输入框自动聚焦。

快捷键冲突时可在 `chrome://extensions/shortcuts` 修改。命令已绑定时由 Chrome 处理；命令未绑定时，网页内的默认组合键作为兜底。修改绑定后刷新网页，旧组合键就不再被页面兜底拦截。书签搜索命令没有页内兜底：未绑定或被其他扩展占用时，点击侧栏顶部的「书签搜索」标签进入即可。

## 书签搜索

点击侧栏顶部的 **书签搜索** 标签进入，或按 `Alt + Shift + F` 唤起。自动关闭侧栏使用 Chrome 141+ 的 Side Panel API，因此插件要求 Chrome 141 或更新版本。

- 输入关键字即时模糊搜索，命中范围覆盖书签名称、URL 和所在文件夹；支持空格分隔多个关键字（所有关键字都命中才保留，例如 `react 文档`）。
- 结果按相关度排序：标题前缀命中 > 标题包含 > URL / 文件夹命中，同分时更短的标题靠前，默认最多展示 50 条。
- 点击结果或按 Enter 在**新标签页**打开书签；新标签页创建成功后侧栏自动关闭，再次按 `Alt + Shift + F` 可重新唤起。↑↓ 移动选择，按 Esc 可直接关闭侧栏，标题栏的 × 也能关闭；要回到表单剪贴板，点击顶部的「表单剪贴板」标签。
- 侧栏打开期间，书签的增删改会自动刷新当前搜索结果；读取失败时保留已有结果并显示重试入口。书签数据只读自浏览器，不经侧栏存储。

## AI 书签整理与新收藏自动分类

在「书签搜索」点击「智能整理」，展开「AI 服务设置（可选）」后填写 **OpenAI 兼容服务地址、模型名称、API Key**。地址可以是 `https://your-service.example/v1` 或完整 `/chat/completions` 地址；本机服务支持 `http://localhost:端口/v1`、`http://127.0.0.1:端口/v1`，服务不要求 Key 时可留空。保存时只申请该服务域名的访问权限。更换服务地址不会沿用旧服务的 Key；同一地址留空则保留已存 Key，清除凭据可用「移除配置」。

- **已有书签**：可选择整个书签栏或其中一个文件夹，点击「生成 AI 整理预览」。AI 结合标题、去除查询参数/片段/账号密码后的网址、已有目录及每目录最多两个样例判断主题，优先复用目录；不会抓取网页正文。生成过程不移动书签。行内会区分「有建议·待采用」「无建议·保持原位」「目标在原位」等状态；只有存在与当前位置不同的目标目录时，才提供勾选和「采用目标」。采用后分类判定不变，只增加「已选入批次」标记，取消勾选即可退出批次；也可展开本条手填目标或点「改分类」修正。无目标或目标仍在原位的条目不会提交移动。确认目标目录后应用，也可撤销批次。规则预览与 AI 预览共用界面，须点击生成按钮才调用 AI。
- **分类依据**：综合内容平台按文章主题分类，不简单按域名归到同一目录；手动固定和用户规则优先。模型自报置信度不是准确率保证；无目标的不确定项保持原位，弱线索等低置信度建议则等待人工采用。请求失败或响应条目缺失、重复、未知 ID 时不应用模型结果。
- **新收藏**：保存配置后开启「收藏新网页时使用 AI 智能放置」。通过 Chrome 星标 / `Ctrl+D` 新增到**书签栏顶层**的 http(s) 收藏进入队列；修改标题后重新等待并使用最终标题。已选择子文件夹的收藏保留用户位置；移动、删除、排序和导入期间取消相关任务。新收藏任务持久化，后台休眠后由定时任务恢复，状态和失败原因显示在整理页。
- **补整理与恢复**：「立即整理书签栏未归类收藏」会按已开启的 AI / 用户规则处理顶层现有收藏。自动移动也有撤销记录。预览后被修改的书签会跳过；中断批次可对账恢复。整理时默认勾选删除范围内空目录（含原有空目录），可取消；撤销批次会恢复被删除的空目录。
- **本地配置**：Key 保存在独立本机存储中，不放进状态消息、整理日志或同步存储。书签分类数据会发往你配置的服务。恢复旧版整理数据时保留规则与日志，但自动化开关默认关闭，需重新开启。

开发验证：`npm test -- tests/bookmark-ai.test.ts tests/bookmark-organizer.test.ts tests/bookmark-row-state.test.ts`；构建后运行 `node scripts/verify-bookmark-organizer.mjs`，使用隔离 Chromium、本地模拟 AI 和测试书签验证配置、目标采用与取消勾选、无目标/同目录状态、预览分页、移动、撤销、新收藏自动分类、单条修正后保留勾选与页码，以及返回前的未应用改动确认，不操作用户的真实书签。截图输出到 `.vitest-attachments/bookmark-organizer/`。该检查不代表真实模型的分类质量验收。

侧栏复制或预览填充遇到多个表单时会列出候选，让用户选择目标；快捷键和右键菜单优先操作明确聚焦的表单或可见弹窗，无法确定时不会猜测。更新插件后，在扩展管理页重新加载插件并刷新业务网页，再重新复制源表单；此前已经复制错的历史记录不会自动恢复。

编辑弹窗内复用带 `query-form` / `filter-form` 类名的组件时，仍会采集业务字段；弹窗外的查询表单、分页与全局搜索区域，以及隐藏和敏感字段仍按原规则过滤。
业务表单内的 `type="search"` 字段和 `<aside>` 中的编辑表单可复制；单独的搜索框表单在自动选择时不会抢过业务表单。

复制和填充支持普通页面、可注入的 iframe、开放的 Shadow DOM，以及普通 `contenteditable` 文本控件。封闭的 Shadow DOM 无法由内容脚本访问；复杂富文本编辑器若不接受合成输入事件，会在填充回读时报告失败。

## 动态表单兼容

业务表单常按选项切换整套字段（例如「新增指标」选择 `MiniBoard` 或 `DashBoard` 后，右侧字段完全不同）。粘贴时按以下规则处理：

- 先填下拉、单选、开关等会触发联动的控件，再填文本类控件；字段在前置控件选择后才渲染时，最多等待 2 秒重扫再填。
- 目标字段因重渲染换了定位 key 时，按标签、name、placeholder 等语义重新匹配；多个同标签候选并存时不猜测，跳过并报告原因。
- 决定表单形态的字段（标签或 name 含「类型 / 类别 / type / mode」的下拉、单选）在目标已有不同值时默认保留，避免粘贴把目标表单切成另一套字段。预览页的「表单形态开关」可以逐项勾选覆盖。
- 目标表单上必填、但源记录里没有对应值的字段（例如切到 `MiniBoard` 后新增的「所属页面」）会在预览页「目标页需手工补全」中列出；AntD 星号、Element `is-required` 这类容器级必填标记同样识别。

## 输入值替换

展开首页底部的「高级设置」后提供 **全局输入值替换** 总开关，**默认关闭**，并预置下方的域名转换规则。需要时打开开关即可，无需逐字段配置，也无需重新复制。开关状态保存在本地；预览页可以切换同一个开关，`Alt + Shift + V` 一键粘贴也读取最新设置。

展开 **配置全局规则** 可以添加、编辑、排序、单条启用/停用或删除规则，点击 **保存全局规则** 后对所有新旧表单生效。保存或试算规则不会自动打开总开关；主动删除全部规则后不会重新补回默认规则。

未保存的全局规则草稿在侧栏页面之间切换时会保留；已暂存的草稿在同一浏览器会话内关闭再打开侧栏时也可恢复。草稿不会影响粘贴，点击 **放弃修改** 可清除；若另一窗口已更新正式规则，需要核对草稿并明确允许覆盖后才能保存。

- **固定文本**：按字面替换，例如查找 `a`、替换为 `b`；`.`、`$1` 等没有特殊含义。
- **正则表达式**：填写正则本身，不加 `/ /`；替换值支持 `$1`、`$2` 捕获组。例如查找 `user-(\d+)`、替换为 `member-$1`。
- 多条已启用规则从上到下执行，替换全部匹配并区分大小写，替换内容留空表示删除。已启用规则的查找内容为空或正则非法时不能保存。
- 全局规则作用于文本、URL、邮箱、电话、数字输入和多行文本，不改变下拉框、单选框等选项标识。原始复制值保持不变，只在粘贴时替换。
- 仍可在记录详情配置可选的字段专属规则：先解析模板变量，再执行全局规则，最后执行字段规则；总开关关闭时两类规则都不执行。粘贴预览中手动覆盖的唯一字段值优先，原有模板变量和唯一字段功能不受总开关影响。

记录详情中的名称、字段值、固定状态、勾选和字段专属替换规则统一点击 **保存更改** 写入；有未保存修改时点击 **预览并填充** 会先保存。返回历史时会提示是否放弃未保存修改。

预置域名规则：正则 `\.demo\.ehi\.com\.cn(?=[:/?#]|$)`，替换为 `.1hai.cn`，即可把 `https://hsmsh5.demo.ehi.com.cn/resumeDetail` 变为 `https://hsmsh5.1hai.cn/resumeDetail`。配置区支持试算，实际结果也可在粘贴预览中检查。

## 隐私与安全

已保存的表单数据仅保存在 `chrome.storage.local`，未应用的全局规则草稿暂存在本次浏览器会话的 `chrome.storage.session`。表单模块不会上传表单数据、自动提交表单或点击确认按钮；密码、验证码、Token、Secret、API Key、信用卡及文件字段默认排除。登录页可以复制账号等普通字段，密码和验证码不会进入历史记录。
