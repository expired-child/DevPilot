# DevPilot

DevPilot 是一个可扩展的 Chrome 开发者效率插件。当前版本提供独立的 **Form Clipboard / 表单剪贴板** 模块。

## 开发

```bash
npm install
npx playwright install chromium
npm run lint
npm run typecheck
npm test
npm run build
```

构建产物位于 `dist/`。在 Chrome 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”并选择 `dist`。

测试使用真实 Chromium DOM，覆盖弹窗与多表单选择、隐藏页签、重复字段、复制粘贴往返和联动重渲染。

## 快捷键

- `Alt + Shift + C`：复制当前表单
- `Alt + Shift + V`：一键把最近复制的表单填充到当前页（不打开面板，页内 toast 汇总结果；唯一字段自动追加 `-2`/`-3` 后缀避免重复）

快捷键冲突时可在 `chrome://extensions/shortcuts` 修改。

复制和粘贴优先操作可见弹窗；普通页面有多个表单时，先点一下目标表单内的输入框。更新插件后，在扩展管理页重新加载插件并刷新业务网页，再重新复制源表单；此前已经复制错的历史记录不会自动恢复。

编辑弹窗内复用带 `query-form` / `filter-form` 类名的组件时，仍会采集业务字段；弹窗外的查询表单、分页与全局搜索区域，以及隐藏和敏感字段仍按原规则过滤。

## 输入值替换

首页提供 **全局输入值替换** 总开关，**默认关闭**，并预置下方的域名转换规则。需要时打开开关即可，无需逐字段配置，也无需重新复制。开关状态保存在本地；预览页可以切换同一个开关，`Alt + Shift + V` 一键粘贴也读取最新设置。

展开 **配置全局规则** 可以添加、编辑、排序、单条启用/停用或删除规则，点击 **保存全局规则** 后对所有新旧表单生效。保存或试算规则不会自动打开总开关；主动删除全部规则后不会重新补回默认规则。

- **固定文本**：按字面替换，例如查找 `a`、替换为 `b`；`.`、`$1` 等没有特殊含义。
- **正则表达式**：填写正则本身，不加 `/ /`；替换值支持 `$1`、`$2` 捕获组。例如查找 `user-(\d+)`、替换为 `member-$1`。
- 多条已启用规则从上到下执行，替换全部匹配并区分大小写，替换内容留空表示删除。已启用规则的查找内容为空或正则非法时不能保存。
- 全局规则作用于文本、URL、邮箱、电话、数字输入和多行文本，不改变下拉框、单选框等选项标识。原始复制值保持不变，只在粘贴时替换。
- 仍可在记录详情配置可选的字段专属规则：先解析模板变量，再执行全局规则，最后执行字段规则；总开关关闭时两类规则都不执行。粘贴预览中手动覆盖的唯一字段值优先，原有模板变量和唯一字段功能不受总开关影响。

预置域名规则：正则 `\.demo\.ehi\.com\.cn(?=[:/?#]|$)`，替换为 `.1hai.cn`，即可把 `https://hsmsh5.demo.ehi.com.cn/resumeDetail` 变为 `https://hsmsh5.1hai.cn/resumeDetail`。配置区支持试算，实际结果也可在粘贴预览中检查。

## 隐私与安全

表单数据仅保存在 `chrome.storage.local`。插件不会上传数据、自动提交表单或点击确认按钮；密码、验证码、Token、Secret、API Key、信用卡及文件字段默认排除。
