# DevPilot

DevPilot 是一个可扩展的 Chrome 开发者效率插件。当前版本提供独立的 **Form Clipboard / 表单剪贴板** 模块和 **书签搜索 / 书签整理** 模块。

## 开发

```bash
npm install
npx playwright install chromium
npm run lint
npm run typecheck
npm test
npm run build
```

构建产物位于 `dist/`。在 Chrome 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”并选择 `dist`。
点击工具栏中的 DevPilot 图标会打开常驻侧栏，复制、编辑和预览填充都在这里完成。

测试使用真实 Chromium DOM，覆盖弹窗与多表单选择、隐藏页签、重复字段、复制粘贴往返和联动重渲染。

## 快捷键

- `Alt + Shift + C`：复制当前表单。页面有多个表单且焦点或弹窗无法确定目标时，会提示先聚焦目标输入框，或到侧栏选择。
- `Alt + Shift + V`：直接把最近复制的表单填充到当前页，跳过预览（页内 toast 汇总结果；唯一字段自动追加 `-2`/`-3` 后缀避免重复）。目标不明确或模板变量未填写时不会修改页面，并会提示原因。侧栏中的填充入口会先打开预览，唯一字段可在预览中手动调整。
- `Alt + Shift + F`：打开书签搜索——侧栏自动打开（或聚焦）并跳转到书签搜索页，输入框自动聚焦。

快捷键冲突时可在 `chrome://extensions/shortcuts` 修改。命令已绑定时由 Chrome 处理；命令未绑定时，网页内的默认组合键作为兜底。修改绑定后刷新网页，旧组合键就不再被页面兜底拦截。书签搜索命令没有页内兜底：未绑定或被其他扩展占用时，点击侧栏首页的「⌕ 书签搜索」按钮进入即可。

## 书签搜索

侧栏首页点击 **⌕ 书签搜索** 进入，或按 `Alt + Shift + F` 唤起。自动关闭侧栏使用 Chrome 141+ 的 Side Panel API，因此插件要求 Chrome 141 或更新版本。

- 输入关键字即时模糊搜索，命中范围覆盖书签名称、URL 和所在文件夹；支持空格分隔多个关键字（所有关键字都命中才保留，例如 `react 文档`）。
- 结果按相关度排序：标题前缀命中 > 标题包含 > URL / 文件夹命中，同分时更短的标题靠前，默认最多展示 50 条。
- 点击结果或按 Enter 在**新标签页**打开书签；新标签页创建成功后侧栏自动关闭，再次按 `Alt + Shift + F` 可重新唤起。↑↓ 移动选择，按 Esc 可直接关闭侧栏，标题栏的 × 也能关闭；要回到表单历史，点击左上角返回按钮。
- 侧栏打开期间，书签的增删改会自动刷新当前搜索结果；读取失败时保留已有结果并显示重试入口。书签数据只读自浏览器，不经侧栏存储。

## 书签整理

书签页顶部可在 **搜索 / 浏览 / 整理** 三个模式间切换；搜索模式的快捷键与键盘语义保持不变。

- **浏览**：按用途分组展示书签（业务系统、研发运维、监控日志、设计文档、AI 工具、网络账号），每组显示条数与文件夹数；只有分类确定为某用途的书签进入对应分组，分类不确定的条目集中显示在「待确认」。顶部汇总待确认与冲突数量；搜索结果可按用途、项目、环境筛选。提供「保存当前页到推荐文件夹」入口：先给出目标建议，保存前可修改标题与目标路径。
- **整理**：分「扫描 → 预览 → 应用 → 结果/撤销」四步。预览把书签分为移动、保持、待确认、冲突（以及用户标记「不要自动移动」的固定项），按目标文件夹分组，每行展示原路径 → 目标路径、分类理由与证据，可展开查看完整 URL 并逐条修改目标。只有确定项默认勾选；待确认与冲突必须手动选择。可只整理某个文件夹。默认删除整理后为空的普通文件夹，包含原本就为空的目录和嵌套目录；保留范围根、系统/受管理目录和目标路径，删除前重新确认没有内容。也可取消清理，或只清理空目录。
- **AI 智能整理**：在整理页填写并保存 DeepSeek 官方 API Key 即可，无需设置地址或模型；默认请求 `https://api.deepseek.com/chat/completions`，使用 `deepseek-flash` 非思考模式。点击「生成 AI 整理预览」才调用，按主题推荐目录，优先复用已有目录；手动分类、固定条目和用户规则优先保留。每批最多 20 条，低置信度条目保留为待确认；响应不完整或失败时保留原预览，生成过程不修改书签。只上传标题、网址的 origin/path 和目录，不上传查询参数、片段或网址中的账号密码。Key 保存在独立的本机 `chrome.storage.local` 键中，可替换或移除，不进入同步存储及操作日志。
- **应用与撤销**：应用前后台会重新核对每条书签的 ID、网址、标题与原位置，预览后发生外部变化的条目会跳过并写明原因；单项失败不影响其余条目，失败项可重试。每个批次的操作日志在写入前落盘，撤销先重建本批次删除的空目录（Chrome 会分配新 ID），再把书签移回并尽量恢复原顺序，最后只删除本批次新建且仍为空的目标文件夹；旧版存档批次仍支持撤销。浏览器中断后的未完成批次会在下次进入整理页时提示对账恢复。批次日志保存在独立的 `bookmarkOrganizer:v1` 存储键中，保留未完成批次与最近 10 个已完成批次。
- **分类规则**：分类只依据标题、URL 域名/路径与所在文件夹名称，内置高辨识度工具规则（代码平台、配置中心、链路追踪、构建与质量平台、原型设计、监控日志、AI 工具、网络账号等）。用户手动修正可「仅修正此条」，或保存为同域名 / 路径前缀规则；路径前缀始终限定在创建规则的网站域名内，保存前会列出会命中的现有条目。用户规则优先于内置规则，原文件夹名称只是弱线索，私有 IP 地址本身也不决定用途。同名但不同网址的书签独立分类，非 http(s) 网址默认待确认，标题与网址暗示的环境不同会标为冲突。
- **新书签自动归档**：默认关闭。显式开启后，仅当新书签命中**用户保存的规则**且判定为确定项时才自动移动；导入书签、受管理节点、模糊条目与扩展自建目录都不触发，可随时关闭并查看最近的自动移动记录。
- **收藏时 AI 智能放置**：在整理页保存 DeepSeek Key 后，开启「收藏新网页时使用 AI 智能放置」。通过 Chrome 星标 / `Ctrl+D` 新增到书签栏的网页，在标题稳定 1.5 秒后按已有目录和主题推荐位置，优先遵循用户规则；有把握才移动，低置信度或接口失败时保留原位置并记录原因。手动移动、删除、排序和导入期间停止处理，应用前再次检查书签与规则是否变化；自动移动有批次日志，可撤销。Chrome 没有提供原生收藏弹窗“完成”的扩展事件，因此这是收藏后的异步处理。移除 Key 会关闭自动 AI 放置。
- 新收藏的待整理任务会保存在本机，后台休眠或浏览器重启后继续处理，并通过 `alarms` 唤醒恢复；恢复前核对标题、网址和原父目录，已被编辑、移动或删除的书签不再自动放置。已有未完成批次时，在自动整理记录中提示先对账或撤销。升级前已经丢失的待处理任务不能自动找回，可在整理页生成 AI 预览后应用。
- 开启自动放置后，后台约每 30 秒补检新收藏到书签栏顶层的网页，补处理漏报的创建事件；首次启动补检最近 5 分钟新增的条目，后续只检查该观察起点之后的新增条目。已处理、手动移动、删除和导入的条目不会重复尝试。AI 开关附近显示收到收藏、分类及放置结果；“立即整理书签栏未归类收藏”可补整理顶层已有网页，逐条推荐并复用前一条创建的同类目录，不处理已归入文件夹、固定或手动指定目录的书签。
- **保存当前页的 AI 推荐**：浏览模式点击「保存当前页到推荐文件夹」，可点击「AI 推荐文件夹」后检查、修改目标再保存；开启自动 AI 放置时，打开保存面板会自动获取推荐。手动指定的保存目标不会被新增书签监听再次改写。推荐过程不直接保存，失败时仍可手动指定目录。

侧栏复制或预览填充遇到多个表单时会列出候选，让用户选择目标；快捷键和右键菜单优先操作明确聚焦的表单或可见弹窗，无法确定时不会猜测。更新插件后，在扩展管理页重新加载插件并刷新业务网页，再重新复制源表单；此前已经复制错的历史记录不会自动恢复。

编辑弹窗内复用带 `query-form` / `filter-form` 类名的组件时，仍会采集业务字段；弹窗外的查询表单、分页与全局搜索区域，以及隐藏和敏感字段仍按原规则过滤。
业务表单内的 `type="search"` 字段和 `<aside>` 中的编辑表单可复制；单独的搜索框表单在自动选择时不会抢过业务表单。

复制和填充支持普通页面、可注入的 iframe、开放的 Shadow DOM，以及普通 `contenteditable` 文本控件。封闭的 Shadow DOM 无法由内容脚本访问；复杂富文本编辑器若不接受合成输入事件，会在填充回读时报告失败。

## 输入值替换

首页提供 **全局输入值替换** 总开关，**默认关闭**，并预置下方的域名转换规则。需要时打开开关即可，无需逐字段配置，也无需重新复制。开关状态保存在本地；预览页可以切换同一个开关，`Alt + Shift + V` 一键粘贴也读取最新设置。

展开 **配置全局规则** 可以添加、编辑、排序、单条启用/停用或删除规则，点击 **保存全局规则** 后对所有新旧表单生效。保存或试算规则不会自动打开总开关；主动删除全部规则后不会重新补回默认规则。

未保存的全局规则草稿在侧栏页面之间切换时会保留；已暂存的草稿在同一浏览器会话内关闭再打开侧栏时也可恢复。草稿不会影响粘贴，点击 **放弃修改** 可清除；若另一窗口已更新正式规则，需要核对草稿并明确允许覆盖后才能保存。

- **固定文本**：按字面替换，例如查找 `a`、替换为 `b`；`.`、`$1` 等没有特殊含义。
- **正则表达式**：填写正则本身，不加 `/ /`；替换值支持 `$1`、`$2` 捕获组。例如查找 `user-(\d+)`、替换为 `member-$1`。
- 多条已启用规则从上到下执行，替换全部匹配并区分大小写，替换内容留空表示删除。已启用规则的查找内容为空或正则非法时不能保存。
- 全局规则作用于文本、URL、邮箱、电话、数字输入和多行文本，不改变下拉框、单选框等选项标识。原始复制值保持不变，只在粘贴时替换。
- 仍可在记录详情配置可选的字段专属规则：先解析模板变量，再执行全局规则，最后执行字段规则；总开关关闭时两类规则都不执行。粘贴预览中手动覆盖的唯一字段值优先，原有模板变量和唯一字段功能不受总开关影响。

记录详情中的名称、字段值、固定状态、勾选和字段专属替换规则统一点击 **保存更改** 写入；有未保存修改时点击 **预览并填充** 会先保存。返回历史时会提示是否放弃未保存修改。

预置域名规则：正则 `\.demo\.ehi\.com\.cn(?=[:/?#]|$)`，替换为 `.1hai.cn`，即可把 `https://hsmsh5.demo.ehi.com.cn/resumeDetail` 变为 `https://hsmsh5.1hai.cn/resumeDetail`。配置区支持试算，实际结果也可在粘贴预览中检查。

## 隐私与安全

已保存的表单数据仅保存在 `chrome.storage.local`，未应用的全局规则草稿暂存在本次浏览器会话的 `chrome.storage.session`。插件不会上传数据、自动提交表单或点击确认按钮；密码、验证码、Token、Secret、API Key、信用卡及文件字段默认排除。登录页可以复制账号等普通字段，密码和验证码不会进入历史记录。
